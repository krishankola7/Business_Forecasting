# Business_Forecasting

Business Forecasting – Time Series Analysis on Monthly Revenue Data
This project applies advanced time series forecasting techniques to monthly revenue data using Python. The workflow includes data preprocessing, visualization, trend and seasonality decomposition, stationarity checks (ADF test), and autocorrelation analysis (ACF/PACF) and L-Jung Box Test. Models implemented include ARMA, ARIMA, SARIMA and forecasted the exchange rate for the next 10 years. Model performance was evaluated using MAPE and RMSE to select the optimal model for future revenue predictions. This project showcases practical applications of statistical forecasting methods for business decision-making.
